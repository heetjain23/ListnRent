# ListnRent Web App 🌐

Frontend web application for ListnRent.

---

## ⚙️ Tech Stack

- React (Vite)
- Tailwind CSS

---

## 🚀 Setup

```bash
npm install
npm run dev

```

## 🌍 Environment Variables

Create a .env file:

VITE_API_URL=http://localhost:5000

## 📁 Structure

src/
├── assets/
├── components/
├── pages/
├── services/
├── hooks/
├── utils/
├── constants/

## 🎯 Features

Browse listings
View outfit details
Create listings
Booking flow (MVP)

## 🧠 Notes

Uses centralized API service
Designed for scalability with mobile app
